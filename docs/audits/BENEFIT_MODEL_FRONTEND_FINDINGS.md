# تحليل واجهة المستخدم (Frontend Analysis)

## مكون `BenefitPolicyRulesTab.jsx`

تم استعراض واجهة إعداد قواعد التغطية والمنافع، وتبين ما يلي:

### 1. سبب التكرار البصري في الجدول
الجدول الموحد (`UnifiedMedicalTable`) يعتمد على مصفوفة بيانات ناتجة عن دمج قائمتين مختلفتين:
```javascript
const benefitRows = rules.map(rule => { ... });
const groupRows = benefitStructure.groups.map(group => { ... });
return [...benefitRows, ...groupRows];
```
- **القواعد (Rules)** تُجلب من نقطة النهاية (`GET /rules`) وتتضمن تصنيفات مثل `CAT-DME`.
- **المجموعات (Groups)** تُجلب من نقطة النهاية (`GET /structure`) وتتضمن المجموعات التي يمكن أن تسمى بأسماء مشابهة مثل `G-CAT026` وتحتوي على نفس التصنيف `CAT-DME`.
- **النتيجة**: الواجهة لا تخفي التصنيف الفردي (Rule) بمجرد دخوله في المجموعة (Group). كلاهما يعرضان كصفوف مستقلة في نفس الجدول، مما يخلق تكراراً بصرياً ويُظهر سقفين منفصلين (سقف الفردي بجوار سقف المجموعة).

### 2. شارة "بلا سقف أو مجموعة" 
في الكود، يتم التحقق من الربط عبر:
```javascript
const bucketLinks = structureLinksByRuleId.get(rule.id) || [];
rule.isLinked = bucketLinks.length > 0;
```
إذا أضاف المستخدم قاعدة فردية وأعطاها `amountLimit` عبر نافذة "السقف الفردي"، ولم يربطها بمجموعة من خلال واجهة "مجموعات المنافع والسقوف"، ستظهر شارة `بلا سقف أو مجموعة` باللون الأحمر، على الرغم من أن لها سقفاً فردياً. هذا يسبب التباساً بصرياً (Confusing UX) للمستخدم.

### 3. غياب استبعاد التصنيفات المرتبطة
عند إضافة تصنيف جديد عبر `RuleFormModal`، تقوم الواجهة بجلب جميع التصنيفات المرجعية:
- لا توجد عملية تصفية (Filtering) تستبعد التصنيفات الموجودة مسبقاً كأعضاء في مجموعات من قائمة الإضافة الحرّة.
- يسمح هذا السلوك للمستخدم باختيار تصنيف موجود ضمن مجموعة، وإضافته كقاعدة مستقلة من جديد.

## الخلاصة المتعلقة بالواجهة الأمامية
* **التكرار ليس بصرياً فقط بل حقيقي**: تكرار العرض في الواجهة نابع من تكرار حقيقي في البيانات المرجعة من الباك إند (صف يمثل القاعدة وصف يمثل الوعاء/المجموعة).
* **غياب ميزة Expand/Collapse**: المنظومة تفتقر لعرض شجري يضع القواعد الفرعية بداخل المجموعات الخاصة بها ويخفيها من القائمة الرئيسية لضمان الحصرية.
* **غياب Validation الواجهة**: الواجهة لا تمنع تكرار إضافة التصنيف إلى الوثيقة إذا كان موجوداً مسبقاً ضمن مجموعة.
